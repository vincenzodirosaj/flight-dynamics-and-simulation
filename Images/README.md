# Reference images

This folder contains figures illustrating the **F/A-18 HARV 6-DoF investigation**
and the **Simulink speed-brake study** discussed in the [project report](../Report/Flight_Dynamics_and_Simulation_Di_Rosa_2023-2024.pdf).

The velocity comparison shown in the main README places the speed-brake and
baseline responses side by side, with speed brakes on the left.
